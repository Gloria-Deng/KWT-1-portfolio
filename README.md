# KWT-1｜RISC-V 关键词识别线性层加速器

KWT-1 将 Keyword Transformer 编码器的第一线性层映射到定点 RTL，并通过 NICE 自定义指令接入 Hummingbird E203 SoC。这个作品集展示设计与验证结果，同时提供可运行的核心 RTL、合成测试与 Python 参考实现。不包含训练数据、原始报告或内部环境。

## 数据路径

```text
RISC-V CPU ── NICE 指令 ──► KWT-1 控制器
                                  │
QSPI Flash ── 输入与权重 ──► 定点乘加、舍入与饱和 ──► 共享 SRAM
```

单次计算把 99 × 64 的输入与 64 × 256 的权重相乘并加偏置，写回 99 × 256 的结果。设计重点是定点重标定、参数布局和计算到写回的数据调度。优化版在等待 SRAM 写应答时预取下一字，并将 QSPI 分频从 3 调到 2。

## 验证结果

| 指标 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 吞吐量 | 146.6 任务/秒 | 170.0 任务/秒（+16.0%） |
| 单任务能耗 | 2.64 mJ | 2.27 mJ（−13.7%） |

优化版采用 12 位权重、16 位输出。加速器新增面积估算为 **0.654 mm²**。在独立的软件定点验证中，单任务最大 NRMSE 为 **0.0668%**。

吞吐量按 150 MHz 折算，不含 CPU 读回；能耗和面积为 TT、1.10 V、25 °C 下的 EDA 评估，不是流片实测。仿真使用固定输入，结果不代表正式赛事评测。单任务能耗降低来自任务完成更快，不表示平均功耗降低。

## 开源复现

发布内容使用 [Apache License 2.0](LICENSE)。完整操作步骤、依赖和测试边界见[复现说明](repro/README.md)。

```sh
cd repro
python3 reproduce.py --frame --protocol
```

已验证：W12/O16 核心 RTL 对一帧合成输入的 25,344 个输出与 Python 整数参考实现逐项一致。定点舍入、W10/W12 乘加、NICE 控制协议分别有独立测试。整帧用行为级 SRAM，控制协议用模拟核心；这些测试不复现整机 Flash/CPU 读回、赛事数据或商业 EDA 的时序、面积和能耗。
